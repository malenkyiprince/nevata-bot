# Установка на Vercel с бесплатными внешними API

Всё приложение работает на Vercel. Никаких Docker, Ollama, собственного сервера или постоянно включённого компьютера. Groq выполняет анализ, Tavily — поиск. После подключения локальные файлы и VS Code можно закрыть.

## 1. Получи три ключа

- Telegram: создай бота командой `/newbot` у [BotFather](https://t.me/BotFather).
- Groq: создай API-ключ в [консоли Groq](https://console.groq.com/keys), используй Free Plan.
- Tavily: создай бесплатный аккаунт и ключ в [Tavily](https://app.tavily.com). Оставь бесплатный Researcher, без Pay As You Go.

Не нужно создавать платный аккаунт Mistral. Безлимитной бесплатной работы нет. При исчерпании квоты приложение показывает ошибку; платного резервного API и повторных запросов в коде нет. Если самостоятельно включить платные тарифы у провайдеров, их условия оплаты будут применяться — код не управляет тарифом твоего аккаунта.

## 2. Подготовь настройки

Распакуй архив, открой папку `bavovna-vercel-free` в VS Code. В терминале:

```sh
python3 scripts/init_env.py
```

На Windows команда может называться `python`. Появится `.env` со случайным `TELEGRAM_WEBHOOK_SECRET`. Скрипт не перезаписывает существующий файл.

**pip и установка Python-библиотек на компьютере не нужны.** Оба скрипта подключения используют только стандартную библиотеку. Зависимости приложения установит Vercel.

## 3. Первый deployment

1. Загрузи содержимое папки в свой Git-репозиторий. `.env` исключён в `.gitignore`: секреты в Git не добавляй.
2. Vercel → Add New → Project → импортируй репозиторий.
3. Root Directory — папка с `vercel.json`. Framework — FastAPI. Build Command и Output Directory вручную не задавай.
4. Для первого deployment задай `PREVIEW=1`. Нажми Deploy.
5. Скопируй постоянный Production URL, например `https://my-bavovna.vercel.app`.

Deployment должен открываться публично, без входа в аккаунт Vercel: иначе Telegram не сможет доставить webhook.

## 4. Внеси переменные

Заполни локальную `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=твой_токен_Telegram
GROQ_API_KEY=твой_ключ_Groq
TAVILY_API_KEY=твой_ключ_Tavily
APP_URL=https://твой-production-домен.vercel.app
TELEGRAM_WEBHOOK_SECRET=секрет_созданный_скриптом
ANALYSIS_TIMEOUT=180
PREVIEW=0
```

В Vercel → Settings → Environment Variables добавь те же значения для Production. Секрет webhook должен совпадать с локальным. После изменения переменных сделай **Redeploy**.

Открой `https://ТВОЙ-ДОМЕН/health`. Должно быть:

```json
{"status":"ok","configured":true,"preview":false}
```

Это проверка настроек, а не реальный вызов Groq/Tavily. Квота не расходуется.

## 5. Подключи Telegram

Если старая версия бота работает через polling, останови тот процесс. Затем из папки проекта:

```sh
python3 scripts/connect_telegram.py
```

Скрипт установит webhook на Vercel и кнопку Mini App. Ожидающие сообщения не сбрасываются. Отправь `/start` своему боту, нажми «Відкрити Бавовну», вставь короткое проверяемое утверждение и нажми «Перевірити».

Материалы проверяются **внутри Mini App**. Обычные сообщения боту вызывают кнопку открытия приложения. История хранится только на устройстве пользователя.

## 6. Для личного использования ограничь доступ

Отправь `/id` боту. Полученный ID добавь в Vercel:

```dotenv
ALLOWED_TELEGRAM_IDS=твой_числовой_ID
```

Сделай Redeploy. Несколько ID перечисляются через запятую. Пустое значение открывает доступ всем пользователям Telegram: они расходуют общую квоту владельца.

## Бесплатные лимиты

По опубликованным условиям на 10 ноября 2026:

- Tavily Researcher: 1000 кредитов в месяц. Один basic search — один кредит. Код делает до двух поисков на проверку. Для ссылок дополнительно вызывается basic Extract, который также расходует кредиты. Поэтому 500 — лишь ориентир числа текстовых проверок с двумя поисками, не гарантированная квота для всех режимов.
- Groq: квоты различаются по модели и аккаунту. Кроме запросов в день есть токены в минуту и в день; длинный материал или фото могут исчерпать минутный лимит даже при небольшом числе проверок. Актуальные значения смотри в своей [Limits](https://console.groq.com/settings/limits).
- Vercel также имеет лимиты бесплатного плана. Это не безлимитный публичный сервис.

Для старта оставь бесплатные планы; не включай платный Pay As You Go. Провайдеры могут менять квоты и доступность моделей.

## Если появилась ошибка

| Ошибка | Что сделать |
| --- | --- |
| Только просмотр дизайна | PREVIEW=0 и Redeploy |
| Открой через Telegram | используй кнопку бота, не обычную вкладку браузера |
| Лимит Groq/Tavily | дождись обновления квоты; платный тариф не обязателен |
| Нет доступа Groq | проверь ключ и доступность GPT-OSS 120B / Qwen 3.8 в аккаунте |
| Ссылка не читается | вставь текст или скриншот страницы |
| Модель не завершила ответ | сократи материал; ошибочный ответ не показывается как фактчек |
| Сессия истекла | закрой Mini App и открой снова |
| Telegram не подключается | проверь публичный Production URL, переменные, Redeploy и Function Logs |

Во время проверки не закрывай Mini App. При обрыве часть квоты могла уже израсходоваться. Восстановления серверного задания и автоматических повторов нет; повторное нажатие запускает новую проверку.

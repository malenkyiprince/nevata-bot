# Бавовна: Vercel + Groq Free + Tavily Free

Светлый Telegram Mini App для проверки текста, ссылок и скриншотов. Только Vercel для размещения приложения; внешние Groq и Tavily используются по API. Начни с [INSTALL.md](INSTALL.md).

## Как работает

1. Telegram webhook возвращает кнопку открытия Mini App. Долгого анализа в webhook нет.
2. Mini App отправляет материал на Vercel с подписанным Telegram initData. Сервер проверяет подпись, срок и необязательный список разрешённых ID.
3. Для ссылки Tavily Extract сначала читает исходную страницу. Если это невозможно, приложение просит текст/скриншот, а не угадывает содержание по URL.
4. Qwen 3.8 27B через Groq выделяет главные утверждения и составляет до двух запросов. В режиме фото эта же модель читает изображение.
5. Tavily выполняет до двух basic search параллельно. auto_parameters отключён, автоматического перехода на advanced нет.
6. GPT-OSS 120B через Groq сравнивает до пяти выдержек с исходным материалом и выдаёт отдельные вердикты, ссылки по ID и границы проверки.
7. Ответ возвращается тем же HTTP-запросом. История сохраняется в localStorage на устройстве, без базы и очереди.

## Точность и ограничения

Модель получает ограниченные выдержки, а не полный интернет. Текст — до 4000 символов, фото JPEG/PNG/WebP до 3 МБ и 20 Мп. Длинная исходная веб-страница обрезается до 4000 символов с явным предупреждением; числовая оценка при этом скрывается.

В ответе могут быть только ссылки из найденных Tavily источников, на которые модель действительно сослалась по ID. Выдуманные URL из текста модели не становятся источниками. Поисковый сниппет помечен отдельно от извлечённого текста. Для числовой оценки нужны достаточность по мнению модели и цитаты как минимум из двух доменов с извлечённым текстом. При неизвестных ID, непроверенном утверждении, частичной ошибке поиска или нехватке данных оценка скрывается.

Эти проверки формата не доказывают правдивость ответа или независимость сайтов. Число — ориентировочное мнение модели о риске манипуляции, не вероятность истины. Проверяется до пяти основных утверждений; остальное не считается проверенным. Модель может ошибаться, в том числе при чтении фото и оценке источников.

## Бесплатная работа

Нужны аккаунты Groq Free и Tavily Researcher. Сам код не включает платный тариф и не переключает провайдера. Но он не может запретить списания, если владелец самостоятельно активировал платные планы. При исчерпании квот запрос завершается понятной ошибкой, без автоматического повтора.

По умолчанию запрос ограничен 180 секундами, Vercel Function — 300. Нет глобальной очереди, серверной истории, постоянного счётчика квоты и межсерверной дедупликации. Повторные запросы/несколько устройств расходуют квоту заново. Для личного запуска рекомендуется ALLOWED_TELEGRAM_IDS.

Код размещён на Vercel; локально нужны лишь два разовых скрипта Python без pip. Vercel сам устанавливает серверные зависимости. Реальный deployment и API требуют ключей владельца.

## Данные

Текст и фото отправляются Groq, поисковые запросы и исходные ссылки — Tavily. Запросы могут содержать фрагменты пользовательского материала. Политики хранения определяются провайдерами; приложение не обещает отсутствие их технических журналов. На Vercel нет базы истории; интерфейс хранит короткую подпись, дату, результат и источники в браузере конкретного устройства. Фото в историю не записывается. Автоматического удаления записей нет.

## Разработка

Для локальной разработки, в отличие от обычного подключения, зависимости нужны:

```sh
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -q
```

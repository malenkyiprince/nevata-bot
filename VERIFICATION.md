# Проверка сборки Vercel Free

Дата: 2026-11-10.

- 31 тест прошёл на Python 3.9.6; deployment настроен на Python 3.12.
- Проверены подпись и срок Telegram initData, разрешённые ID, preview, webhook, фото, неверные/большие входные данные и статические файлы.
- Проверены планирование, два basic search без auto_parameters, отдельная vision-модель, чтение ссылки до анализа, обрезка длинной страницы с явным предупреждением, отсутствие источников, неверные ID, сниппеты, один домен, частичная ошибка поиска, лимит 429 без повторов, незавершённый JSON и общий тайм-аут.
- Проверены подключение Telegram без pip, сохранение ожидающих updates и отказ при ненастроенном deployment.
- JavaScript прошёл синтаксическую проверку Node.js.
- Python-файлы и JSON-конфигурация проверены на синтаксис.
- Схемы Groq Vision/JSON, модели и параметры Tavily сверены с официальной документацией. Зависимости и настройки Vercel взяты из предыдущей проверенной сборки.

Автотесты используют имитацию Groq/Tavily и ASGI-клиент. Настоящие API-ключи отсутствуют: рабочие квоты, доступность моделей для аккаунта владельца, качество ответов и deployment Vercel ещё не проверены. /health проверяет только наличие/формат настроек, без реальных внешних вызовов.

Никакие аккаунты, платные планы, webhook или deployment в ходе подготовки не изменялись. Предыдущие архивы сохранены.

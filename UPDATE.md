# Перейменування: НеВата / NeVata

1. Скопіюй вміст архіву в поточну папку свого Git-проєкту, погодься замінити однойменні файли. Папку проєкту й репозиторій перейменовувати для роботи не потрібно. .env не змінюй.
2. У терміналі VS Code:

```sh
git add api/index.py config.py research.py easter_egg.py inflight.py static scripts pyproject.toml
git commit -m "Rename app to NeVata"
git push
```

3. Дочекайся Ready нового коміту в Vercel.
4. Для зміни відображуваного імені Telegram і кнопки меню один раз виконай локально:

```sh
python3 scripts/rename_bot.py
```

pip не потрібен. Скрипт читає чинну .env, задає NeVata для англійської та типово для інших мов, НеВата — для української, а також назву кнопки «Відкрити НеВату». Токен, username, URL і webhook не змінюються. Попередні повідомлення в чаті не редагуються; нове привітання видно після /start.

5. Повністю закрий Mini App й відкрий знову.

Якщо в BotFather окремо встановлено стару назву Mini App, її також потрібно змінити там вручну. Код не перейменовує GitHub-репозиторій або Vercel-проєкт і не змінює адресу deployment. Це зберігає чинний APP_URL і підключення Telegram.

## Що змінено

- Українська назва в інтерфейсі: НеВата.
- Англійська назва та метадані: NeVata.
- Привітання, кнопки, підписи маскотів і текст пасхалки.
- Назва пакета Python: nevata.
- Скрипт першого підключення вже задає нову кнопку меню.

Ключ localStorage залишено історичним, щоб не втратити наявну історію на тому ж домені. Маскоти, пасхалка, оптимізації й аналіз контексту збережені. Архів містить усі картинки та серверні файли.

Офіційний метод Telegram: https://core.telegram.org/bots/api#setmyname
